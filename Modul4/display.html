Display CSS

Ini adalah elemen pertama menggunakan DIV
Ini DIV di dalam DIV namun membuat elemen blok baru Ini SPAN di dalam DIV tidak membuat elemen blok baru


Kesimpulan:
• <div> secara default adalah elemen block akan selalu memulai baris baru dan mengambil lebar area yang tersedia.
• <span> secara default adalah elemen inline yang akan tampil dalam baris yang sama dengan teks lain
• Dengan display: block pada span, akan dipaksa berperilaku seperti block sehingga background merah terlihat memenuhi lebar elemen utama nya
